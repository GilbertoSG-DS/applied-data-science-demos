# Applied Data Science Demos

This repository contains practical demonstrations of applied data science techniques used in real-world business decision making.

The notebooks cover topics such as forecasting, experimentation, feature engineering, and retrieval-augmented generation (RAG).

## Topics covered

### Forecasting
- Model comparison (ARIMA / Prophet / ML)
- Forecasting with exogenous variables
- Hierarchical forecasting

### Advanced Forecasting

- GARCH volatility modeling for financial time series
- Financial time series analysis (NSE data)

### Experimentation
- A/B testing
- Power analysis

### Machine Learning
- Feature engineering for behavioral models

### LLM / AI
- Retrieval-Augmented Generation (RAG) pipeline

## Purpose

These demos were built as conceptual and practical exercises to reinforce key data science concepts such as:

- time series forecasting
- causal experimentation
- statistical inference
- feature engineering
- vector search and RAG systems
